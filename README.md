# Real Madrid Event Dashboard ⚽🏟️

A full-stack web application designed to manage stadium events, track live ticket analytics, and monitor Santiago Bernabéu capacity and estimated revenues.

## Features

* **CRUD Event Management:** Create, view, update, and delete upcoming matches and events.
* **Real-time Analytics:** KPI cards displaying total events, upcoming matches, total capacity, and projected revenue.
* **Modern UI/UX:** Glassmorphism dashboard styled with official Real Madrid branding and Santiago Bernabéu backdrop.
* **Robust Backend:** RESTful Express API connected to a PostgreSQL database.

## Tech Stack

* **Frontend:** React, Vite, CSS3
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Version Control:** Git, GitHub
